**Встановити або оновити однією командою** — у PowerShell (права адміністратора не потрібні; скрипт бере інсталятор останнього випуску й перевіряє контрольну суму):

```powershell
irm https://raw.githubusercontent.com/SemkoArtem/mhrd/main/windows/install.ps1 | iex
```

Або вручну — файли нижче. Встановлюйте поверх попередньої версії: ваші ПК, налаштування й паролі лишаються.

**Виправлено**
- **Тунелі WireGuard більше не перебивають власні сеанси** і в рідших випадках: коли два ПК через один тунель запускаються майже одночасно; коли MHRD відкривають ярликом ПК (стартова перевірка й сеанс збігались у часі); після перезапуску MHRD, поки вікна сеансів відкриті; коли одночасно працюють встановлена й портативна MHRD; коли два профілі тунелю мають той самий ключ. Усі вони тепер ідуть через один тунель на ключ.
- **Перевірка тунелів більше не обриває сеанси на інших пристроях** з тим самим ключем: тунелі перевіряються при запуску, при зміні профілю й за кнопкою, а не кожні 5 хвилин. У редакторі тунелю — підказка: один ключ WireGuard — на одному пристрої.
- **Автобекап у спільну (хмарну) теку** з кількох пристроїв: пристрої більше не видаляють бекапи один одного — у назві файлу тепер є пристрій, і кожен прибирає лише свої копії.
- **Буфер обміну:** відповідь сервера, що прийшла запізно, більше не підміняє наступне вставлене (наприклад, картинка замість тексту).
- **Мініатюра ПК** не псується, коли до одного ПК відкрито два сеанси різними акаунтами.
- Локальний порт сеансу в тунелі закривається разом із сеансом; затримку до ПК міряємо раз на 30 с (кожен замір — підключення до RDP-порту ПК, і частіші засмічували журнал подій Windows).
- Команда оновлення попереджає й питає, якщо відкриті сеанси (оновлення їх закриє).

Install or update with one PowerShell command: `irm https://raw.githubusercontent.com/SemkoArtem/mhrd/main/windows/install.ps1 | iex` — or use the files below. Your PCs, settings and passwords are kept.

**Fixed:** WireGuard tunnels no longer disturb their own sessions in rarer cases too (two PCs started at once, MHRD opened from a PC shortcut, MHRD restarted while session windows are open, installed and portable MHRD at once, two tunnel profiles with the same key) — all go through one tunnel per key. Tunnel checks no longer drop sessions on other devices with the same key (checked at start, on change and on demand, not every 5 minutes). Auto-backup into a shared cloud folder: devices no longer delete each other's backups. A late clipboard response no longer replaces the next paste. The PC thumbnail is no longer corrupted by two sessions to one PC. Session ports close with their session; latency is measured every 30 s. The update command warns about open sessions.
