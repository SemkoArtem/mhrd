**Встановити або оновити однією командою** — у PowerShell (права адміністратора не потрібні; скрипт бере інсталятор останнього випуску й перевіряє контрольну суму):

```powershell
irm https://raw.githubusercontent.com/SemkoArtem/mhrd/main/windows/install.ps1 | iex
```

Або вручну — файли нижче. Встановлюйте поверх попередньої версії: ваші ПК, налаштування й паролі лишаються.

**Виправлено**
- **Тунелі WireGuard більше не «падають», коли їх кілька.** Кожен сеанс і кожна перевірка тунелю запускали окремий процес з тим самим ключем, і сервер WireGuard перемикався між ними: відкритий сеанс до двох хвилин втрачав зв'язок, а тунелі показувались непрацюючими — тим частіше, чим більше тунелів і сеансів. Тепер один тунель на профіль для всіх його сеансів, перевірки не заважають сеансам і йдуть по черзі.
- **Затримка тунелю** показувалась завжди близько 100 мс — тепер справжня.

Install or update with one PowerShell command: `irm https://raw.githubusercontent.com/SemkoArtem/mhrd/main/windows/install.ps1 | iex` — or use the files below. Your PCs, settings and passwords are kept.

**Fixed:** WireGuard tunnels no longer drop when there are several — every session and every tunnel check used to start its own process with the same key, so the server kept switching between them; now one tunnel per profile serves all its sessions, and checks don't disturb sessions. The tunnel latency is real instead of always ~100 ms.
**New:** four themes — Aurora, Paper, Neon, Terminal.
