**Install or update with one command** — in PowerShell (no admin rights needed; the script takes the installer of the latest release and verifies its checksum):

```powershell
irm https://raw.githubusercontent.com/SemkoArtem/mhrd/main/windows/install.ps1 | iex
```

Or manually — the files below. Install over the previous version: your PCs, settings and passwords are kept.

**Fixed**
- **Dragging a PC into a group on touchscreen laptops and all-in-ones** works every time: immediately with a mouse or touchpad, after a short hold of the card with a finger. Previously, when mouse and finger alternated, dragging could work only every other time.

**Other platforms**
- Android: [MHRD 0.3.4 for Android](https://github.com/SemkoArtem/mhrd/releases/tag/android-v0.3.4) — now a stable release (branch [`android`](https://github.com/SemkoArtem/mhrd/tree/android))
- Linux (alpha): [MHRD 0.2.6 for Linux](https://github.com/SemkoArtem/mhrd/releases/tag/linux-v0.2.6-alpha) — `curl -fsSL https://raw.githubusercontent.com/SemkoArtem/mhrd/linux/linux/install.sh | bash` (branch [`linux`](https://github.com/SemkoArtem/mhrd/tree/linux))

**Verify the download**
The release includes `SHA256SUMS.txt` with checksums. In PowerShell: `Get-FileHash .\mhrd-setup-0.3.4-x64.exe -Algorithm SHA256` — the result must match the line in the file.

**Download:** `mhrd-setup-0.3.4-x64.exe` — installer, `mhrd-0.3.4-x64-portable.zip` — portable version. Windows 10/11, 64-bit.

**Українською**

**Встановити або оновити однією командою** — у PowerShell (права адміністратора не потрібні; скрипт бере інсталятор останнього випуску й перевіряє контрольну суму):

```powershell
irm https://raw.githubusercontent.com/SemkoArtem/mhrd/main/windows/install.ps1 | iex
```

Або вручну — файли нижче. Встановлюйте поверх попередньої версії: ваші ПК, налаштування й паролі лишаються.

- **Перетягування ПК у групу на ноутбуках і моноблоках із сенсорним екраном** спрацьовує щоразу: мишею чи тачпадом — одразу, пальцем — після короткого утримання картки. Раніше, коли чергувались миша й палець, перетягування могло спрацьовувати через раз.
