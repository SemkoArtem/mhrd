**Встановити або оновити однією командою** — у PowerShell (права адміністратора не потрібні; скрипт бере інсталятор останнього випуску й перевіряє контрольну суму):

```powershell
irm https://raw.githubusercontent.com/SemkoArtem/mhrd/main/windows/install.ps1 | iex
```

Або вручну — файли нижче. Встановлюйте поверх попередньої версії: ваші ПК, налаштування й паролі лишаються.

**Виправлено**
- **Перетягування ПК у групу на ноутбуках і моноблоках із сенсорним екраном** спрацьовує щоразу: мишею чи тачпадом — одразу, пальцем — після короткого утримання картки. Раніше, коли чергувались миша й палець, перетягування могло спрацьовувати через раз.

**Інші платформи**
- Android: [MHRD 0.3.4 для Android](https://github.com/SemkoArtem/mhrd/releases/tag/android-v0.3.4) — тепер стабільна версія (гілка [`android`](https://github.com/SemkoArtem/mhrd/tree/android))
- Linux (альфа): [MHRD 0.2.6 для Linux](https://github.com/SemkoArtem/mhrd/releases/tag/linux-v0.2.6-alpha) — `curl -fsSL https://raw.githubusercontent.com/SemkoArtem/mhrd/linux/linux/install.sh | bash` (гілка [`linux`](https://github.com/SemkoArtem/mhrd/tree/linux))

**Перевірка завантаженого**
До релізу додано `SHA256SUMS.txt` з контрольними сумами. У PowerShell: `Get-FileHash .\mhrd-setup-0.3.4-x64.exe -Algorithm SHA256` — результат має збігтися з рядком у файлі.

**Завантажити:** `mhrd-setup-0.3.4-x64.exe` — інсталятор, `mhrd-0.3.4-x64-portable.zip` — портативна версія. Windows 10/11, 64-біт.
