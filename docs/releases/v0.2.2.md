**Перевірка завантаженого**
До релізу додано `SHA256SUMS.txt` з контрольними сумами. У PowerShell: `Get-FileHash .\mhrd-setup-0.2.2-x64.exe -Algorithm SHA256` — результат має збігтися з рядком у файлі.

**Завантажити:** `mhrd-setup-0.2.2-x64.exe` — інсталятор (права адміністратора не потрібні), `mhrd-0.2.2-x64-portable.zip` — портативна версія. Windows 10/11, 64-біт.
