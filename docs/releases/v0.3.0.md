**Встановити або оновити однією командою** — у PowerShell (права адміністратора не потрібні; скрипт бере інсталятор останнього випуску й перевіряє контрольну суму):

```powershell
irm https://raw.githubusercontent.com/SemkoArtem/mhrd/main/windows/install.ps1 | iex
```

Або вручну — файли нижче. Встановлюйте поверх попередньої версії: ваші ПК, налаштування й паролі лишаються.

**Нове**
- **Налаштування нових ПК.** Налаштування → «Нові ПК» → «Налаштувати нові ПК»: маршрут (WireGuard, проксі, RD Gateway), акаунти, екран, звук, мікрофон, буфер обміну, теги — один раз, і з ними створюється кожен новий ПК: «Додати ПК», швидке підключення, імпорт з mstsc. Уже додані ПК не змінюються. Шаблони роздільності — у тому ж розділі.
- **Імпорт зі стандартного клієнта Windows.** «Додати» → «Імпорт з «Підключення до віддаленого робочого стола»»: MHRD показує ПК, які пам'ятає mstsc (адреси з портами й імена користувачів), — ставите галочки, які додати; ті, що вже є, позначено. Паролі Windows не віддає — MHRD спитає під час першого підключення.

**Покращено**
- **Буфер обміну, файли з ПК:** запізніла відповідь сервера більше не може потрапити в інший шматок файлу під час вставляння.

**Перевірка завантаженого**
До релізу додано `SHA256SUMS.txt` з контрольними сумами. У PowerShell: `Get-FileHash .\mhrd-setup-0.3.0-x64.exe -Algorithm SHA256` — результат має збігтися з рядком у файлі.

**Завантажити:** `mhrd-setup-0.3.0-x64.exe` — інсталятор (права адміністратора не потрібні), `mhrd-0.3.0-x64-portable.zip` — портативна версія. Windows 10/11, 64-біт.

Install or update with one PowerShell command: `irm https://raw.githubusercontent.com/SemkoArtem/mhrd/main/windows/install.ps1 | iex` — or use the files below. Your PCs, settings and passwords are kept.

**New:** settings for new PCs (Settings → New PCs): route, accounts, display, sound, microphone, clipboard and tags set once and applied to every new PC (Add PC, quick connect, mstsc import). Import PCs remembered by the built-in Windows client (Add → Import from Remote Desktop Connection) with checkboxes; passwords are asked on first connection.
**Improved:** clipboard file transfer from the PC ignores late server responses.
