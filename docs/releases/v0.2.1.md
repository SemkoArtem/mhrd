Встановіть поверх попередньої версії: ваші ПК, налаштування й паролі лишаються.

**Нове**
- **Тунель WireGuard вручну.** Налаштування → Маршрути → «Створити вручну»: ті самі поля, що й у файлі `.conf` — PrivateKey, Address, DNS, MTU, PublicKey сервера, PresharedKey, Endpoint, AllowedIPs, PersistentKeepalive. Кнопка «Згенерувати ключі» створює новий ключ, а публічний ключ цього пристрою видно одразу з кнопкою «Копіювати» — щоб додати його на сервері WireGuard. Перед збереженням MHRD перевіряє формат ключів і зв'язок із сервером.

**Покращено**
- **Портативна версія:** якщо файл паролів пошкоджено, повідомлення показує точний шлях до нього.

**Перевірка завантаженого**
До релізу додано `SHA256SUMS.txt` з контрольними сумами. У PowerShell: `Get-FileHash .\mhrd-setup-0.2.1-x64.exe -Algorithm SHA256` — результат має збігтися з рядком у файлі.

**Завантажити:** `mhrd-setup-0.2.1-x64.exe` — інсталятор (права адміністратора не потрібні), `mhrd-0.2.1-x64-portable.zip` — портативна версія. Windows 10/11, 64-біт.

Install over the previous version; your PCs, settings and passwords are kept.

**New:** create a WireGuard tunnel manually (Settings → Routes → "Create manually") with the same fields as a `.conf` file; "Generate keys" creates a key pair and shows this device's public key with a Copy button.
**Improved:** the portable version names the exact path when the password file is damaged.
