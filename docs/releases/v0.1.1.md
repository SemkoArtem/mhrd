Оновлення безпеки. Рекомендуємо всім, хто поставив 0.1.0: просто встановіть поверх — ваші ПК, налаштування й паролі лишаються.

**Виправлено**
- **Спільні папки в режимах «Додавати без змін» і «Лише читання».** Віддалений ПК більше не може дописати дані в наявний файл через альтернативний потік NTFS (`файл:потік`) і не проходить крізь символьні посилання та junction-теки всередині спільної папки — ні відкриттям, ні перейменуванням. Правила режиму тепер діють рівно в межах вибраної папки.
- **Буфер обміну з файлами.** Віддалений ПК більше не може змусити MHRD виділити гігабайти пам'яті одним запитом: файл віддається шматками до 16 МБ.
- **Вставка файлів із віддаленого ПК.** Імена файлів від сервера очищаються перед передачею в Провідник: без літери диска, початкового `\`, частин `..` і двокрапок.
- **PIN-код MHRD.** Після трьох невдалих спроб — пауза, що зростає (5 с, 10 с, 20 с… до 15 хв); перезапуск програми її не скидає, вхід через Windows Hello знімає.
- **Імпорт бекапу.** Підроблений файл бекапу з завищеними параметрами шифрування більше не «вішає» програму — його одразу визначено як пошкоджений.

**Перевірка завантаженого**
До релізу додано `SHA256SUMS.txt` з контрольними сумами. У PowerShell: `Get-FileHash .\mhrd-setup-0.1.1-x64.exe -Algorithm SHA256` — результат має збігтися з рядком у файлі.

**Завантажити:** `mhrd-setup-0.1.1-x64.exe` — інсталятор (права адміністратора не потрібні), `mhrd-0.1.1-x64-portable.zip` — без встановлення. Windows 10/11, 64-біт.

Дякуємо за огляд безпеки коду, з якого виросли ці виправлення.

Security update; installing over 0.1.0 keeps your PCs, settings and passwords.

**Fixed:** restricted shared-folder modes no longer allow writing through NTFS alternate data streams or following symlinks/junctions inside the folder; clipboard file transfers are served in chunks of at most 16 MB; file names coming from the server are sanitized before reaching Explorer; repeated wrong PINs now trigger a growing delay; a crafted backup can no longer hang the import. Releases now include `SHA256SUMS.txt`.
