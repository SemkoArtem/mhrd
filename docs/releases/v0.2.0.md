Встановіть поверх попередньої версії: ваші ПК, налаштування й паролі лишаються.

**Нове**
- **Справжня портативна версія.** Zip тепер зберігає все поруч із програмою, у теці `mhrd-data`, — його можна носити на флешці. Паролі й ключі лежать у зашифрованому файлі під майстер-паролем (Argon2id + AES-256-GCM), а не в сховищі Windows; майстер-пароль замінює PIN і відбиток і змінюється в налаштуваннях. Перенести ПК з установленої MHRD: там — повний бекап, тут — «Відновити».
  Якщо ви користувалися zip версії 0.1.x, ваші дані лежать у профілі Windows: перенесіть їх бекапом або видаліть файл `portable.txt` поруч із `mhrd.exe` — тоді програма працюватиме з ними, як раніше.
- **Ярлик ПК на робочому столі.** Меню «⋯» ПК → «Ярлик на робочому столі»: подвійний клік одразу підключає. Для ПК з кількома акаунтами — ярлик і для кожного акаунта окремо.

**Покращено**
- **Ізоляція сеансу.** Процес кожного сеансу сам себе обмежує засобами Windows: не може запускати інші програми, завантажувати бібліотеки з мережевих тек і шрифти не із системи. Якщо в розборі даних від сервера колись знайдеться вразливість, їй буде значно важче розгорнутись.
- **«Усі монітори»** тепер справді працює: віддалений робочий стіл займає всі ваші монітори з тією ж розкладкою, плашка — на основному.
- **HiDPI.** Типово — повна чіткість на екранах з масштабом 125–200 %. Для повільного з'єднання її можна вимкнути в налаштуваннях ПК: трафіку в 2–4 рази менше, картинка м'якша.
- **«Не вимикати екран»** тепер справді працює: поки відкрите вікно сеансу, Windows не гасить екран і не засинає.

**Перевірка завантаженого**
До релізу додано `SHA256SUMS.txt` з контрольними сумами. У PowerShell: `Get-FileHash .\mhrd-setup-0.2.0-x64.exe -Algorithm SHA256` — результат має збігтися з рядком у файлі.

**Завантажити:** `mhrd-setup-0.2.0-x64.exe` — інсталятор (права адміністратора не потрібні), `mhrd-0.2.0-x64-portable.zip` — портативна версія. Windows 10/11, 64-біт.

Install over the previous version; your PCs, settings and passwords are kept.

**New:** a truly portable zip — all data lives in `mhrd-data` next to the program, secrets in a file encrypted with a master password (Argon2id + AES-256-GCM); 0.1.x zip users can migrate via backup or delete `portable.txt` to keep the old behaviour. Desktop shortcuts that connect straight to a PC, also per account.
**Improved:** each session process now restricts itself (no child processes, no remote images, system fonts only); "Use all monitors" now works; HiDPI-exact rendering is the default with an economy mode for slow links; "Keep screen awake" now works.
