Перший публічний випуск MHRD для Windows — безкоштовного RDP-клієнта з відкритим кодом (AGPLv3).

**Завантажити:**
- `mhrd-setup-0.1.0-x64.exe` — інсталятор. Права адміністратора не потрібні (ставиться для вас; за бажанням — для всіх).
- `mhrd-0.1.0-x64-portable.zip` — без встановлення: розпакуйте й запустіть `mhrd.exe`.

Потрібна Windows 10 або 11, 64-біт. Програма ще не підписана сертифікатом, тож Windows SmartScreen може попередити: «Докладніше» → «Однаково запустити».

**Що вміє**
- Кожен віддалений робочий стіл — в окремому вікні й процесі; кілька сеансів одночасно.
- Вбудований WireGuard без прав адміністратора, проксі SOCKS5/HTTP, RD Gateway; стан тунелів і проксі в лівій панелі.
- Плашка сеансу: перетягується до будь-якого краю, затримка до ПК у мс, Ctrl+Alt+Del, повний екран.
- Перепідключення при обриві (до 5 спроб), сенсорний екран як на самій Windows, H.264.
- Буфер обміну (текст, картинки, файли), спільні папки, звук, мікрофон.
- Групи, мініатюри, шаблони екрана, «Недавні» на значку в панелі завдань.
- Паролі — лише в сховищі Windows; зашифрований бекап; блокування PIN-кодом і Windows Hello.
- Українська та англійська мови, теми.

Про помилки й побажання — у [Issues](https://github.com/SemkoArtem/mhrd/issues).
